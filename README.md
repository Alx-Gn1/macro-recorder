# Easy to use macro recorder

## How to use

Ctrl + Shift + R - to start recording (same combinaison to stop the record)

Ctrl + Shift + X - to execute a recorded macro

You can force a macro execution to stop by pressing Ctrl + Shift + X again, or by pressing Ctrl + Shift + C

https://github.com/Alx-Gn1/macro-recorder/blob/main/assets/screenshot.png

# Installation

## Linux
Download and run the appImage or .deb package at the root of the project

## Windows or MacOS :

Check tauri required dependencies : https://tauri.app/start/prerequisites/

then
```
cd src-main
npm run tauri build

```

installer can be found in src-tauri/target/release/bundle
